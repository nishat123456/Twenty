# Twenty

*Twenty questions before you buy.*

Twenty is a SwiftUI app for evaluating stocks with a 20-point value investing checklist inspired by Warren Buffett. Answer the questions for a stock, get a score out of 20 with a recommendation, and export the result as a PDF.

## Features

- 20-question checklist with a plain-English explanation for every question
- Auto-fill for 6 financial questions using live data from Financial Modeling Prep
- Score and recommendation (Strong Buy, Moderate Buy, Not Recommended)
- Saved evaluations that can be edited later
- PDF report export

## Running the app

1. Open `Buffet Strat App.xcodeproj` in Xcode.
2. Choose an iPhone simulator and press Run (⌘R).
3. To use Auto-fill, get a free API key at [financialmodelingprep.com](https://financialmodelingprep.com) and enter it in the app's Settings.
